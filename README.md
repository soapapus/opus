# Opus

캘린더와 메모를 한곳에. 자기 일정·성과·메모를 정리하는 개인용 Windows 앱(Electron + React).

- 설치본: [Releases](../../releases/latest) 에서 `Opus-<버전>-setup.exe` 를 받아 실행
- 변경 내역: [CHANGELOG.md](CHANGELOG.md)
- 개발 규칙(사람·AI 공통): [AGENTS.md](AGENTS.md)

```
npm ci
npm run dev     # 개발 실행
npm test        # 테스트
npm run dist    # Windows 설치본
```
