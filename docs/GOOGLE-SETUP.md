# Google 연동 설정

Opus 0.8.0에서는 **설정 → Google 연동** 한곳에서 캘린더, Drive, Gemini를 설정합니다.

## Google Cloud 프로젝트

1. https://console.cloud.google.com 에서 프로젝트를 선택합니다.
2. API 및 서비스 → 라이브러리에서 **Google Calendar API**, **Google Drive API**, **Generative Language API**를 사용 설정합니다.
3. Google Auth Platform에서 동의 화면을 설정합니다. 테스트 상태라면 연결할 계정을 테스트 사용자로 추가합니다.
4. 사용자 인증 정보에서 **데스크톱 앱** 유형의 OAuth 클라이언트를 만듭니다.
5. 클라이언트 ID와 보안 비밀을 Opus 설정에 입력합니다. 집·회사 PC에서 같은 Google Cloud 프로젝트의 같은 클라이언트 ID를 사용합니다.
6. Gemini용 API 키를 같은 프로젝트에서 발급하고 Generative Language API로 제한합니다. Gemini API 키는 OAuth 클라이언트 보안 비밀과 다릅니다. Google AI Studio에서 해당 프로젝트의 키를 만들 수도 있습니다.
7. Opus에 Gemini API 키와 사용 가능한 모델 이름을 입력하고 **Google 설정 저장**을 누릅니다. 기본 모델 별칭은 `gemini-flash-latest`입니다. 키·모델의 실제 사용 가능 여부와 과금은 Google 프로젝트를 따릅니다.

API 사용 설정·동의 화면 구성은 Google 콘솔에서 해야 합니다. Opus가 프로젝트 관리자 권한을 요청하거나 콘솔 설정을 자동 변경하지는 않습니다. 회사 계정의 외부 앱 연결·개인 계정 사용은 조직 정책을 따릅니다.

## 한 번의 Google 권한 승인

- 캘린더 읽기는 기본입니다.
- **캘린더 쓰기**를 켜면 `calendar.events`를 추가 요청합니다. 자동으로 전체 일정을 전송하지 않고, 사용자가 일정 편집 메뉴에서 내보낸 일정만 추가합니다.
- **Drive 읽기·쓰기**를 켜면 `drive` 권한을 추가 요청합니다. 기존 폴더 및 공유 드라이브를 직접 선택할 수 있게 하기 위한 계정 전체 Drive 권한입니다. Opus 구현은 선택한 폴더의 조회·다운로드와 새 ZIP 추가만 사용하며 원격 파일 수정·삭제 API는 사용하지 않습니다.
- **선택한 권한으로 Google 연결/다시 연결**을 누르면 선택한 권한들을 한 OAuth 요청으로 승인받습니다. 최종 승인한 권한이 연결 상태에 표시됩니다. Gemini API 키는 별도 인증입니다.
- 권한 스위치만 바꾸면 기존 토큰은 바뀌지 않습니다. 다시 연결해야 적용됩니다. Google 계정의 기존 앱 승인 자체를 철회하려면 계정의 연결된 앱 설정에서 철회합니다.

## Drive 백업과 자료실

1. 개인 계정의 내 드라이브에 `Opus` 폴더를 만들거나, 사용 가능한 공유 드라이브 내 폴더를 준비합니다.
2. Opus에서 **Drive 폴더 조회 → 폴더 선택 → 백업 폴더 적용**을 누릅니다. 쓰기 권한이 없는 폴더는 적용하지 않습니다.
3. **지금 Drive 백업**으로 첫 ZIP을 만듭니다. 원본은 PC에도 남습니다.
4. **Drive 자동 백업**을 켜면 앱 실행 중 현재 워크스페이스를 1시간마다 백업하고, 5분마다 실패한 업로드를 재시도합니다. 자동 백업은 각 PC·워크스페이스에서 별도로 켭니다. 앱이 꺼져 있으면 실행되지 않습니다.
5. 자료실에서 선택 폴더의 파일을 검색하고 Google Drive에서 열거나 내려받습니다. 하위 폴더의 내용은 이번 버전에서 재귀 조회하지 않습니다. Google 문서는 브라우저에서 엽니다.

메모·직접 작성한 일정·빠른 메모·AI 대화와 기존 보관 기록은 ZIP에 포함됩니다. 외부 Google 일정, OAuth 토큰, Gemini 키, 검색 색인은 제외됩니다. 기존 ZIP은 자동 삭제하거나 덮어쓰지 않습니다. 실패 큐는 PC에 남고 연결이 복구되면 재시도합니다. 응답이 유실된 업로드를 재시도하면 같은 내용의 ZIP이 추가로 생길 수 있습니다.

백업 ZIP은 내려받아 **새 폴더**에 풀고 메모 파일을 확인할 수 있습니다. 자료실의 ZIP에서 **기록 합치기 미리보기**를 누르면 새 기록·갱신·충돌 사본 수를 확인하고 가져올 수 있습니다. 설정의 **다른 PC 백업 자동 병합**을 켜면 자동 백업도 함께 켜지고, 5분마다 다른 장치의 최신 백업을 읽어 합칩니다. 장치별 증가 번호로 최신 ZIP을 찾고, 메모의 내용 해시와 조상 버전으로 변경을 판정합니다. PC 시각이나 파일 수정 시각만으로 덮어쓰지 않습니다.

한쪽만 바꾼 기록은 이어서 갱신하며 양쪽이 다르게 수정했으면 사본을 남깁니다. 백업에 없는 로컬 기록은 지우지 않고, 로컬에서 보관한 기록을 과거 백업으로 다시 활성화하지 않습니다. AI 대화가 갈라지면 별도 대화로 보존하고 AI 탭의 대화 선택에서 읽을 수 있습니다. 병합 직전의 전체 로컬 백업과 가져온 원본 ZIP도 PC의 백업 폴더에 보존합니다.

자동 병합은 같은 워크스페이스 ID와 같은 Drive 폴더의 새 형식 백업만 대상으로 합니다. 기본 개인 워크스페이스는 두 PC 모두 `personal`이며, 별도로 만든 공간은 ID가 다를 수 있습니다. 이전 버전 ZIP은 병합 이력이 없으므로 두 PC를 업데이트하고 새 백업을 만들어야 합니다. 병합은 압축 전·후 각각 100MB 이하의 기록 ZIP에 한정합니다. 메모·일정·빠른 메모·보관 기록·AI 대화를 합치며, 임의 첨부 파일을 현재 자료에 자동 덮어쓰지는 않습니다. 원본 ZIP은 그대로 남습니다.

백업 자체는 앱 실행 중 최대 1시간 간격이므로 실시간 동기화가 아닙니다. 다른 PC로 이동하기 전에 **지금 Drive 백업**으로 최신 기록을 올릴 수 있습니다. 기존 Google Drive 데스크톱 폴더 기반 동기화도 사용할 수 있지만, 처음에는 한 방식을 선택해 사용하는 것을 권장합니다.

## Gemini AI

AI 탭에서 직접 입력한 질문과 최근 최대 30개 대화 메시지를 Gemini로 전송합니다. 메모·Drive 자료·회사 일정은 자동 첨부하지 않습니다. 요금과 사용 한도는 키가 속한 프로젝트를 따릅니다.

질문은 네트워크 요청 전에 로컬에 저장합니다. 오류가 나도 질문과 이전 대화는 유지하며, 성공한 응답도 현재 워크스페이스에 저장해 ZIP 백업에 포함합니다. API 키는 PC의 Electron safeStorage로 암호화하며 데이터 폴더·백업·화면 응답에 넣지 않습니다.

## 네이버

설정의 네이버 캘린더 연결에서 네이버 로그인 Client ID/Secret을 저장합니다. 등록 콜백은 `http://127.0.0.1:53682/naver/callback`입니다. 공식 캘린더 API는 일정 추가만 제공하므로 내보내기만 지원합니다. 조회·수정·삭제·양방향 동기화를 제공하는 것으로 표시하지 않습니다.

## 검증 범위

단위 테스트는 가짜 OAuth/API 응답으로 권한 요청, 공유 드라이브 조회, 오프라인 백업 재전송, 기록 보존, Gemini 실패 처리를 검증합니다. 화면 테스트는 브라우저 미리보기 API를 사용합니다. 실제 계정 OAuth 및 실제 Gemini 호출은 사용자 프로젝트의 키·동의 화면·권한 설정을 완료한 후 별도로 확인해야 합니다.
