# PC 자료실 · 개인 프로젝트 · 브라우저

자료실의 **PC 폴더 등록**에서 실제 로컬 폴더를 선택합니다. Google 계정·Drive API는 필요하지 않습니다. Drive 데스크톱이 마운트한 G:도 PC 경로로 등록할 수 있습니다. 해당 PC에서 경로가 연결되어 있어야 합니다.

## 자료실
- 등록 폴더 트리와 최대 4개 탐색창, 주소 입력, 뒤로/앞으로/상위, 검색·정렬, 목록·아이콘 보기를 제공합니다.
- 파일을 두 번 클릭하면 기본 앱에서 엽니다. 다중 선택 후 복사/잘라내기/붙여넣기 또는 다른 탐색창으로 복사/이동합니다. 드래그는 복사, Shift 드래그는 이동입니다.
- 같은 이름이 있으면 덮어쓰지 않고 중단합니다. 이동은 복사본을 검증한 뒤 원본을 운영체제 휴지통으로 보냅니다. 휴지통을 지원하지 않는 위치에서는 오류를 표시하고 원본을 유지합니다.
- 등록 해제는 목록에서만 제거합니다. 심볼릭 링크·정션 경유 접근은 차단합니다.
- 등록 목록은 PC별 설정입니다. 폴더 안 실제 파일은 Opus 백업 ZIP에 자동 포함되지 않습니다. PC 자료실은 파일 동기화 기능이 아닙니다.

## 개인 프로젝트
컬럼을 직접 추가하고 이름·순서·상태를 바꿉니다. 카드 드래그 또는 카드의 이동 목록으로 컬럼을 옮깁니다. 좁은 화면에서는 보드를 가로로 스크롤합니다. 제목·본문·날짜·우선순위·태그·댓글·첨부를 저장합니다. 첨부는 Opus 데이터 폴더로 복사하므로 원본 위치가 바뀌어도 열 수 있습니다. 카드와 컬럼은 보관 후 복원합니다.

보드와 첨부는 워크스페이스 데이터 및 전체 ZIP 백업에 포함됩니다. 보드 수정 전 버전을 보존하며, 오래된 화면에서 저장하면 충돌을 알려 입력을 유지합니다. **현재 두 PC 백업 자동 병합은 메모·AI 대상이며 프로젝트 보드 자동 병합은 지원하지 않습니다.**

## 브라우저
탭·주소 검색·뒤로/앞으로·새로고침·즐겨찾기를 사용합니다. Ctrl+L/T/W를 지원합니다. 웹 콘텐츠는 Node와 Opus API가 없는 별도 sandbox에서 실행합니다. 카메라·마이크 등 권한 요청은 허용하지 않습니다.

Chrome에서 열기는 현재 HTTP(S) 주소를 설치된 Chrome으로 전달합니다. Chrome과 Opus의 로그인·쿠키는 별도입니다. 사이트 정책상 내장 브라우저 로그인이 제한되면 Chrome을 사용합니다. Chrome이 없으면 안내를 표시합니다. 탭·즐겨찾기·웹 세션은 PC별로 보존합니다.

기존 Drive 백업·기록 병합은 설정 → Google 연동 → Drive 백업 목록 · 기록 병합에서 사용합니다.
